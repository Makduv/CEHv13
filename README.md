## What's inside

### The interactive map — `carte.html` (repository root)

The main resource. A single HTML file that runs in your browser — no installation, no account.

- **Module-by-module mind map** following the CEH v13 curriculum
- **Short, scenario-based quizzes** for each module
- **Cheat sheet per module**
- **Tools & commands** — what each tool does, with a command cheat sheet
- **Ports & services** reference (TCP/UDP annotated)
- **Cross-cutting concepts** that span several modules
- **Express revision** and a **general quiz** across all modules
- **French / English** interface
- **Light / dark mode**

### Study notes

- Personal notes from the official EC-Council CEH v13 courseware
- Personal notes from the *CEH Certified Ethical Hacker v13 Study Guide*

All notes are my own summaries and reformulations, written for revision.
